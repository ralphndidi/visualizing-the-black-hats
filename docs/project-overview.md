# Project Overview

## Activity
Visualizing the Black Hats — research and analysis of three hypothetical cyberattackers.

## Purpose
To identify attacker profiles, motives, attack methods, target assets, vulnerabilities, and mitigation measures.

## Scope
This is a desk-based educational analysis of the three scenarios in the supplied assignment. It does not include scanning, exploitation, access to third-party systems, or collection of real personal data.

## Deliverables
- Threat actor comparison
- Scenario-by-scenario analysis
- Findings and defensive recommendations
- Evidence log and screenshot placeholders
- References
