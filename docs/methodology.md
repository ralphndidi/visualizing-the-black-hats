# Methodology

1. Review the assignment scenario.
2. Extract explicitly stated facts.
3. Identify the actor and motivation described in the scenario.
4. Identify the attack method and target.
5. List stated weaknesses separately from plausible weaknesses.
6. Recommend preventive, detective, and recovery controls.
7. Document assumptions and limitations.

## Evidence handling
Only genuine assignment material, notes, and screenshots should be placed in this repository. Redact personal or confidential information before publishing.
